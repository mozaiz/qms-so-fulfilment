Use this phone as a scanner

A browser only gives a camera to a page it trusts. Setting this up takes about a minute, once per phone — after that the camera works for good, with no internet needed.

Install the store certificate
Install certificate

iPhone & iPad — two taps after installing

2
Settings → Profile Downloaded → Install (top right) → Install → enter your passcode.
3
Settings → General → About → scroll to the bottom → Certificate Trust Settings → turn ON the switch next to QMS Store Certificate Authority.

Do not skip this step. Installing alone is not enough — Apple requires the extra switch before Safari will trust it.

Android — what to expect

2
Android may warn that the file could harm your device. Choose Continue / Install anyway. It is the store's own certificate, generated on the store computer.
3
Name it QMS when asked, and choose CA certificate if Android offers a choice. You will be asked to confirm your screen lock.
4
Some Android phones need this instead — in Chrome, open chrome://flags, search for unsafely-treat-insecure-origin-as-secure, paste the http address below, and relaunch Chrome. That skips the certificate entirely.

Not working?
• Camera still blocked on an iPhone — almost always step 3. Check Settings → General → About → Certificate Trust Settings is switched on.
• "Cannot connect" — the phone must be on the same wifi as the store computer, and must use the address above, not localhost. localhost means "this phone" and will never work.
• Certificate error after a while — the store computer's IP address changed. Re-run the certificate helper on the store computer.
